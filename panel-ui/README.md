# SOC Analyst Panel

React/Vite analyst UI served by the backend at `/panel/`.

## Development

```bash
npm install
npm run dev
```

Set `VITE_API_URL` only when the API is hosted separately. When the panel is served by Express, the default same-origin API base is used.

## Data behavior

- Alerts use server-side filtering and pagination from `GET /alerts`.
- Dashboard metrics come from `GET /dashboard/stats` and are calculated from persisted alert/analysis data.
- The 24h / 7d / 30d selector changes the backend date range.
- No synthetic MTTD/MTTA/MTTR, MITRE technique, confidence, risk score, or threat-timeline values are generated by the UI.
- AI analysis is analyst-triggered.
- Existing persisted analysis is viewed without a new LLM call.
- `Re-run AI` explicitly requests a new analysis and appends a new analysis summary.
- Observed Evidence, Detection Logic, and AI Assessment are rendered separately.
